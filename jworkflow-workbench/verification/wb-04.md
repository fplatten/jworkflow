## Finding: Unicode command-line arguments on Windows

With the default ANSI code page (1252 here), `java -jar "…\jar proof 漢字\jworkflow-workbench.jar"` fails with `Unable to access jarfile …\jar proof ??\…`: the Windows `java` launcher converts arguments through the ANSI code page. A Unicode **working directory** works. The smoke therefore launches with a relative JAR path and `.` as the project. The same limitation applies to a Unicode project-directory argument. Users can launch from inside the folder or edit the suggestion in the browser. Record in the WB-24 user guide.
